# Reiy

雷伊, a compact lightning warrior pet inspired by a popular Seer character, simplified for Codex.

## Files

- `pet.json` - Codex pet manifest.
- `spritesheet.webp` - Codex pet v2 animation atlas, 8 columns x 11 rows, `1536x2288`.

Rows 0-8 contain the standard animation states. Rows 9-10 contain 16 clockwise look directions in 22.5-degree steps.

## Install

```bash
mkdir -p ~/.codex/pets
cp -R pets/reiy ~/.codex/pets/reiy
```
