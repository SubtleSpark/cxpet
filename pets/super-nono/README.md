# Super NONO

A footless hovering cyan-and-white robot PET inspired by Super NONO.

## Files

- `pet.json` - Codex pet manifest.
- `spritesheet.webp` - 8x11 Codex pet animation atlas, `1536x2288`, with version 2 looking directions.

## Install

```bash
mkdir -p ~/.codex/pets
cp -R pets/super-nono ~/.codex/pets/super-nono
```
